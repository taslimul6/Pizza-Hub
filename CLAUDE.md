# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Status

PizzaHub is an early-stage Next.js app. The home page is a static design built from section components (no backend, auth or real data yet; sample data lives at the top of each component). There is no test framework.

Components are organized by page: `app/components/homepage/` holds the home page sections (composed in `app/page.tsx`), and `app/components/shared/` holds components used on every page (`Navbar`, `Footer`, rendered in `app/layout.tsx`). Code style is beginner-friendly: one component per file, `useState` only, plain comments.

Design intent lives in [docs/](docs/): `docs/New Text Document.txt` is the branding plan (tagline, palette, fonts, home-page sections, next steps) and `docs/initial layout.html` is a static HTML mock of the home page. Treat them as the spec when building UI:
- Colors: tomato red `#C8261B` (primary), basil green `#2F6B3A`, cheese gold `#FFB81C`, espresso `#2A1A14` (text), cream `#FFF8EE` (background).
- Fonts: Fraunces (headings), DM Sans (body), loaded in `app/layout.tsx` and exposed as `font-display` / `font-sans`.
- Style: pill buttons, rounded cards, warm shadows, 4/8px spacing.
- Home page: role-based navbar (Customer / Vendor / Admin), hero search, shops, menu tabs, offers, vendor CTA, reviews, app/newsletter, footer.

## Next.js version warning

`AGENTS.md` states this Next.js (16.x, React 19) has breaking changes from what you may know. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (sections: `01-app`, `02-pages`, `03-architecture`, `04-community`).

## Architecture notes

- App Router only (`app/`); path alias `@/*` maps to the repo root.
- `next.config.ts` enables non-default features that affect how pages must be written: `cacheComponents: true`, `partialPrefetching: true`, and `experimental.agentFeedback`. Check the docs for caching/dynamic-data rules under Cache Components before fetching data in components.
- `layout.tsx` uses the globally generated `LayoutProps<"/">` type (no import needed).
- Tailwind CSS v4 is configured via `@import "tailwindcss"` in `app/globals.css` with theme tokens in an `@theme inline` block (no `tailwind.config`). Turbopack processes CSS through `@tailwindcss/turbopack` (rule in `next.config.ts`). Brand colors, fonts and shadows are already defined there as theme tokens (e.g. `bg-primary`, `text-muted`, `shadow-warm-md`).
- `cacheComponents` makes `new Date()` fail the prerender, so avoid it in static components.
- `AGENTS.md` is regenerated by `next dev`; commit it rather than deleting it.
